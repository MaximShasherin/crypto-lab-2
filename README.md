# Лабораторная работа №2. Стеганография и шифрование

## Требования
- Python 3.x
- Библиотеки: `Pillow`, `numpy`, `pycryptodome`, `scipy`, `scikit-image`, `matplotlib`.
Установка:
pip install pillow numpy pycryptodome scipy scikit-image matplotlib

## Запуск
1. Исходное изображение `my_photo.png` должно лежать в папке `imgs/`.
2. Запустите скрипт: `python src/stego.py`.
3. Результаты сохранятся в папки `imgs/` и `results/`.
